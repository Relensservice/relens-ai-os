# ReLens AI OS V5 — Premium Mobile Edition

## Run
1. Copy `.env.example` to `.env`
2. Add an OpenAI API key if desired
3. `pip install -r requirements.txt`
4. `uvicorn app.main:app --host 0.0.0.0 --port 8000`
5. Open the project URL

Pages:
- `/` Customer website
- `/dashboard` Owner dashboard

Designed as a premium, rounded-card, purple/blue ReLens experience.
